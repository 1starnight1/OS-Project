# 操作系统课程设计 

## 项目概述

本项目实现了操作系统课程设计基础必做部分的四个核心模块，并在此基础上扩展了**调度与性能优化**功能，使用C语言在Linux环境下开发。

## 项目结构

```
linux_os/
├── scheduler.c      # 处理机调度算法实现（含性能优化）
├── memory.c         # 内存管理与页面置换实现
├── sync.c           # 进程同步与并发控制实现
├── filesystem.c     # 文件系统模拟实现
├── Makefile         # 编译配置文件
└── README.md        # 项目说明文档
```

## 环境要求

- 操作系统：Linux (Ubuntu/CentOS等)
- 编译器：GCC
- 线程库：pthread
- 开发工具：make, gdb

## 编译说明

### 方法1：使用Makefile（推荐）

## 调度与性能优化扩展功能说明

### 多级反馈队列调度 (MLFQ)

**设计原理：**
- 维护3个优先级队列（Q0, Q1, Q2）
- 时间片大小：Q0=2, Q1=4, Q2=8（指数增长）
- 新进程进入最高优先级队列(Q0)
- 用完时间片未完成则降级到下一队列
- 最低优先级队列采用FCFS策略

**特点：**
- 响应时间短：短作业快速完成
- 公平性：长作业最终会执行
- 自适应：根据进程行为动态调整优先级

### 性能分析指标

| 指标 | 定义 | 计算公式 |
|------|------|----------|
| 周转时间 | 进程从到达到完成的时间 | 完成时间 - 到达时间 |
| 等待时间 | 进程在就绪队列等待的时间 | 周转时间 - 执行时间 |
| 响应时间 | 进程从到达到首次执行的时间 | 首次执行时间 - 到达时间 |
| 吞吐量 | 单位时间内完成的进程数 | 进程数 / 总完成时间 |

### 性能对比分析

系统支持自动运行所有算法并生成性能对比报告，帮助分析不同调度算法的优缺点：

- **FCFS**：简单公平，但平均等待时间较长
- **SJF**：平均周转时间最优，但需要预知执行时间
- **RR**：响应时间均匀，适合分时系统
- **Priority**：适合实时系统，需防止低优先级进程饿死
- **MLFQ**：综合性能最优，平衡响应时间和公平性
